# Profile motion source

The animated assets in `../assets/hero.gif` and `../assets/stack.gif` are rendered with [Remotion](https://www.remotion.dev/).

```bash
pnpm install
pnpm studio
pnpm render
```

- `ProfileHero`: name, role and primary-stack motion.
- `TechStack`: TypeScript-led toolkit motion.

Edit the compositions in `src/` and run `pnpm render` to regenerate both GIFs.
